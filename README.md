# Proyecto Modulo 2 : Estructura de control, Excepciones y Colecciones de python

## Descripcion del proyecto
Este proyecto consolida los conociminetos adquiridos sobre estructuras de control, manejo y colecciones de datos practicando en python
Consiste en una aplicasion de consola con el menu interactivoque permite ejecutar datos ingresados por el usuario 
A su ves estos son puestos a prueba en la consola indicando la longuitud de la palabra y el punto en el plano cartesiano

## Funcionalidades del proyecto

### 1. Validacion de longuitud de palabra 
* ** Objetivo:** Se le pide al usuario una palabra al asar dependiendo de lo que quiera escribir, despues se verifica que cumpla con las condiciones en su composicion de 4 letras minimo y un maximo de 8 letras.
* ** Ciclos y Validacion:** Se hace el uso del bucle while para solicitar de forma repetitiva la entrada hasta que el usuario ingrese la palabra correcta.
* ** Uso de Colecciones (Tupla):** Se reguistra cada intento echo por el usuario sea valido o invalido en una configuracion de lista y al final muestra el historial de tods laas palabras

### 2. Ubicasion en el plano cartesiano 
* ** Objetivo:** Se le pide al usuario igresar un dato numerico necesario sea positivo o negativo en dos ocasiones para cada variante (X,Y),estas son buscadas en los cuadrantes (1,2,3,4) y se señala su ubicasion.
* ** Ciclos y Excepciones:** Aplica un bloque "try-except" dentro de un ciclo "while" para validar la respuesta los datos ingresados sean correctos, forzando a que los datos no sean cero.
* ** Uso de colecciones (Tupla):** Almacena los nombres de los cuadrantes en una "tupla" y accede a ellas utilizando los datos numericos precisos y correctos.
